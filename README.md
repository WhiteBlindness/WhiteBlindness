# Duarte

**Industrial Engineering and Management → R&D and innovation consulting → software, automation, and AI agents.**

I work across R&D, innovation, and technology. I’m extending that work by designing and building software that solves concrete problems. I learn the tools each project needs, then carry it through testing and deployment.

## Technologies

TypeScript · React · Next.js · Cloudflare Workers · Python · APIs · LLM tooling · Supabase · Cloudflare D1 · Vitest · GitHub Actions

## Building now

- **[CallBrief](https://github.com/WhiteBlindness/callbrief):** screens R&D funding calls against local documents, with cited findings and offline evaluations.
- **[Roundcraft](https://github.com/WhiteBlindness/roundcraft):** a Counter-Strike 2 round-analysis product with server-side rules and explicit API contracts.
